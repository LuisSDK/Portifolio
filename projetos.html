Os meus projetos

Aqui partilho os projetos que construí e participei até ao momento.

Portefólio Pessoal:

Este mesmo site, construído de raiz com HTML5 semântico, estruturação multi-páginas e versionado no GitHub.

A Minha Cidade:

Uma página dedicada a Braga, com ilustrações SVG, dados históricos e curiosidades regionais.

Receita Tradicional:

Estruturação semântica de uma receita de arroz doce, com lista de ingredientes e modo de preparo.

Festival Gastronómico:

Página informativa sobre o Festival da Sardinha de Portimão, com secções temáticas e testemunhos.

Os Elétricos de Lisboa

Página sobre as linhas de elétrico mais conhecidas de Lisboa, com cartões, etiquetas e uma paleta inspirada nos elétricos amarelos.

Tecnologias: HTML5, CSS3, Google Fonts

Sistema de Gestão de Marcenaria:

Aplicação web desenvolvida com Next.js, React, TypeScript e Supabase para gestão de pequenas marcenarias.

Aplicação de Screener Aeroportuário:

Ferramenta desenvolvida com React, Vite, Supabase e JavaScript para registos de revistas manuais das bagagens de passageiros em aeroportos.

SimpleDocs / BoxSys (Participação):

Sistema de gestão documental e de arquivos, desenvolvido com Next.js, TypeScript, Laravel, PHP, PostgreSQL e Tailwind CSS.

Blue Guard:

Projeto de incubação e desenvolvimento de uma aplicação web para gestão de segurança marítima.

MCP-TEAMS Assistant:

Protótipo de assistente virtual para Microsoft Teams, desenvolvido com Next.js, React, TypeScript e Ollama.

OpenStack AI Chatbot:

Protótipo de chatbot para suporte a utilizadores do OpenStack, desenvolvido com Next.js, React, TypeScript e Ollama.

Portal do Cidadão da Guiné-Bissau:

Protótipo de portal web para serviços públicos, desenvolvido com Next.js, React, TypeScript e Capacitor.

IGRP Design System (Participação):

Desenvolvimento de componentes e documentação para o IGRP Design System, utilizando React, TypeScript, Storybook e shadcn/ui.

Gestão de Negócios (Participação):

Aplicação desenvolvida com Power Apps, Power Fx e Power Automate para gestão empresariais.
